# Task Weaver

![Task Weaver](assets/banner.svg)

Java 任务执行器，按依赖调度任务，让独立步骤并行运行

[English](README.md) · [后续计划](ROADMAP.md)

## 快速体验

需要 JDK 17+ 和 Python 3.11+，Python 仅用于跨平台构建脚本，执行器本身没有第三方运行依赖

```sh
python scripts/build.py --test
java -jar build/task-weaver.jar --zh
```

内置示例先读取合成数据，再并行计算总数与数量，最后生成汇总结果

## 主要功能

- 运行前检查重复任务、缺失依赖和循环依赖
- 使用 1–64 个工作线程调度独立任务
- 将直接依赖的结果传给任务，支持空值
- 记录成功、失败和跳过状态，以及任务实际执行耗时
- 上游失败时跳过下游，独立分支继续执行
- 返回结果按传入顺序排列，单次最多 1,000 个任务

## 接入方式

将 `build/task-weaver.jar` 加入 classpath，或使用 MIT 协议下的源码，示例见英文文档

每个任务包含名称、依赖集合和执行函数，执行函数接收不可修改的依赖结果 Map，值类型为 `Object`，由调用方自行约定

等待 `execute(...).get()` 完成后再关闭执行器，`close()` 是线程池关闭操作，不是取消任务

首版提供进程内执行，不包含分布式调度、持久化、自动重试或超时策略，也尚未发布到 Maven Central
